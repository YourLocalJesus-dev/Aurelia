# AURELIA

## For the unhurried.

AURELIA is a two-part digital experience built around the idea of slowing down, exploring, and experiencing the web differently.

The project consists of two distinct websites:

- AURELIA STUDIO — the main tree, representing the studio atelier.
- AURELIA LABS — the labs tree, an immersive and interactive 3D WebGL experience.

---

## ◇ EXPERIENCES

### AURELIA LABS

An immersive 3D WebGL experience built around interaction, atmosphere, and exploration.

[Visit AURELIA LABS](https://aurelialabs.vercel.app)

### AURELIA STUDIO

The main AURELIA studio atelier, focused on the broader identity and creative direction of the project.
